# Dialogue Implementation Roadmap

This directory contains detailed technical and design specifications for upcoming Dialogue features, as well as completed roadmap items.

## Completed Features

- **Agent Tool-set Expansion** (Completed ✅) — On-demand historical search, transaction-safe task batching, lazy-load task notes, and workspace discovery.

## Core Intelligence

- **[Task & Event Resource Hub](./task_resource_linking.md)**: Contextual resource linking (URLs, documents, Figma specs) directly inside target items to form a unified workspace directory.

## UX Enhancements

- **[Task/Event Scope Pinning](./task_event_scope_pinning.md)**: Click a button on any task or event to pin it as the active scope in chat. Agent context narrows to that entity. No typing required.
- **[Structured Confirmation Modal](./structured_confirmation_modal.md)**: Replace agent's text Q&A with an interactive one-by-one modal with pre-filled options and custom input, for faster task/event creation.

## Platform Features

- **[Context-Aware Notifications](./browser_notifications.md)**: Smart push notifications that leverage Living Task Context to deliver actionable, personalized reminders instead of dumb templates.
- **[Adjustable Memory Sensitivity](./adjustable_memory_sensitivity.md)**: Tactile UI slider giving users absolute agency over the background personality harvesting frequency (Hyper-Adaptive to Manual).

---

*These plans are living documents, updated as the agent and workspace architecture evolve.*
